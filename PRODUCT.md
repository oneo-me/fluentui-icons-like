# Product

## Register

product

## Users

Developers who need Fluent UI System Icons in Svelte, React, or Avalonia projects. They use the preview app to browse icons, filter by metadata, inspect variants and sizes, copy framework snippets, and export SVG or PNG assets.

## Product Purpose

FluentUI Icons Like packages Microsoft Fluent UI System Icons into app-friendly distributions and provides a fast preview surface for discovery and export. Success means users can move from icon search to correct framework usage with minimal context switching.

## Brand Personality

Practical, precise, calm. The interface should feel like a developer tool: dense, predictable, responsive, and focused on the icon workflow.

## Anti-references

- Marketing-heavy icon gallery pages that put promotion ahead of browsing.
- Decorative UI patterns that slow scanning or make controls feel unfamiliar.
- Overly expressive motion, oversized cards, and low-density layouts.
- Inconsistent component styling between filters, catalog tiles, and detail actions.

## Design Principles

- Keep the icon workflow first: filtering, scanning, selecting, copying, and exporting should stay visible and quick.
- Preserve Fluent-style clarity: restrained color, sharp hierarchy, familiar controls, and clear icon affordances.
- Favor local consistency: shared control behavior should look and feel the same across the sidebar, catalog, and details panel.
- Keep generated package information practical: snippets, names, symbols, styles, and sizes should be easy to copy and verify.

## Accessibility & Inclusion

Use semantic controls, visible focus states, readable contrast, keyboard-friendly actions, and reduced-motion-safe feedback for transient copy and loading states.
